# Health Metrics Tracker

A simple React app to track and visualize health metrics like steps and water intake.

## Features

- Input form with validation
- View data as table and chart (Recharts)
- Sort & filter data by time/value
- Data persists via `localStorage`
- Responsive UI (mobile-first)

## Setup

```bash
git clone https://github.com/your-username/health-tracker-app.git
cd health-tracker-app
npm install
npm start
